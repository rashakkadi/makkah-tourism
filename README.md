# Makkah Tourism Website

A multi-page static website introducing visitors to Makkah: its spiritual significance, key landmarks, and practical travel tips.

## Pages

| Page | Description |
|------|-------------|
| `index.html` | Home: welcome section, why visit Makkah, and links to the rest of the site |
| `Makkah.html` | About Makkah: spiritual atmosphere, unity among Muslims, Ramadan in Makkah |
| `places.html` | Tourist places: Al-Masjid Al-Haram, Mount Arafat, Zamzam Well, with images |
| `tips.html` | Travel tips: before you travel, during your visit, helpful reminders |

## Built With

- HTML5
- CSS3 (single shared stylesheet, `style.css`)

## Run Locally

No build step is needed. Clone the repo and open `index.html` in a browser:

```bash
git clone https://github.com/rashakkadi/makkah-tourism.git
cd makkah-tourism
```

Or serve it with any static server, e.g. VS Code Live Server.
